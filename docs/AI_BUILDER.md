# AI Builder

The AI Builder reasons about model, data, evaluation, agents, tools, storage,
interfaces, and deployment while depending only on capability routes. It can
use stored knowledge and project files.

It can scaffold, statically verify, run the fixed approved test paths, and
create deterministic content-addressed artifacts through shared builder tools.
It is not a self-deploying platform: training pipelines, embedding providers,
domain evaluation suites, and target-specific deployment adapters remain
future implementations.
